# Research datasets and historical results

The input datasets and historical output records are separate. No scientific rows, values, filenames or sequence contents were edited during this organization. See [SOURCES.md](SOURCES.md) for attribution and distribution scope; availability does not establish historical paper reproducibility. Run `git lfs pull` after cloning to obtain LFS-backed data files.

## Layout

```text
datasets/
├── __init__.py                    # Python package, keep for imports
├── ki_preference_dataset.py       # Training-pair loader, keep for imports
├── stage1/                       # Indexed CSVs and categorical mapping
├── e2po/                         # Clean ligands, training pairs, held-out references
├── targets/                      # Structural FASTA constructs and active references
├── feature_index/                # Historical index ONLY, not embeddings
├── README.md
└── SOURCES.md
results/
├── generation/                   # The two historical 12-target SMILES runs
└── evaluation/                   # Docking rows, property rows, summary/statistical records
```

## Input semantics and code paths

- Stage one: `stage1/train.csv` has **1,153,824 rows** with integer SMILES/sequence IDs. Decode them with `stage1/categorical_mappings.json` (785,740 SMILES and 6,098 sequences). `valid.csv` and `test.csv` have **115 rows each**; their historical split construction and paper adoption remain unverified. Their filenames do not certify leakage-free splits. The TG and Self-Conditioning entry defaults resolve the relocated training CSV when run from `improved-diffusion/scripts/`.
- Stage two: the current deposited **328,157-pair** `e2po/le_affinity_preserving_preference_pairs_delta1.0.csv` is now the default input of both `KiPreferenceDataset` and `scripts/train_direct_ki_e2po.py`. This replaces a missing legacy `data/bindingdb_ki/preference_pairs_delta1.0_no_test_targets.csv` path. It is an explicit current-data default, **not proof that the historical model used this exact file**. The 55,095-row clean-ligand pool is an intermediate/reference, not a winner/loser pair table. The 4,490 held-out pairs are not the default training input. The 87-row SMILES-only reference has no per-row target labels.
- Targets: `targets/test_target_sequences.csv` has 12 named sequences for preference exclusion. The 12 FASTA files contain one structural construct apiece. Do not equate a sequence-table entry with a FASTA construct merely because the target name matches; lengths/truncations and constructs may differ. Active-reference CSVs are per-target SMILES tables used by novelty/candidate-selection code.
- Features: `feature_index/ap_moldiff_feature_index.csv` contains **1,153,824 historical index rows**, not the roughly 1 TB tensor cache. Historical row paths remain `datasets/output/train_desc_states/<bucket>/<row>.pt`; this cache path was deliberately kept unchanged in the loaders. The released categorical mapping is now found under `datasets/stage1/`. Missing-cache fallback to zero tensors is not valid historical conditioning. The 16,842 previously recorded missing feature paths and the unverified historical 640→1024 projection are not fixed by moving files. Per-cache hashes in the index are historical metadata; only the index file itself was freshly hashed here.
- Results: 24 generation CSVs contain 1,000 attempted SMILES each, retaining `INVALID`. The 24 Vina tables contain selected-molecule docking rows, not all generation attempts. Blank scores remain missing. Two 12,000-row property tables retain their existing provenance/error columns. Historical summary and statistical tables are preserved, not recomputed or newly certified.

## Entry points and explicit inputs

These are path/CLI references, not claims of completed training or fresh paper reproduction. Paths below are relative to the repository root unless noted.

| Task | Existing entry/input |
|---|---|
| TG training | `improved-diffusion/scripts/train_protein_170.py`; launch from its script directory, default `../../datasets/stage1/train.csv` |
| Self-Conditioning training | `improved-diffusion/scripts/train_protein_self_cond.py`; same input/cwd convention |
| Cache preparation | `process_train_csv.py --csv_path ../../datasets/stage1/train.csv --output_dir ../../datasets/output/train_desc_states` from `improved-diffusion/scripts/`; requires ESM/projection resources and is NOT executed here |
| E2PO training input | `scripts/train_direct_ki_e2po.py --csv_path datasets/e2po/le_affinity_preserving_preference_pairs_delta1.0.csv` |
| First-stage target input | `sample_protein_self_cond.py --fasta_dir datasets/targets/fasta` when using an explicit repository-root-relative argument; other required model arguments remain necessary |
| Second-stage target input | `scripts/eval_ki_e2po_12_targets.py`; resolves `datasets/targets/fasta/` and `datasets/targets/actives_bindingdb_cl/`; this combined entry can run generation/docking, so it is NOT used as a path-only test |
| Property input | `tools/ev_molecular_properties.py --gen-file results/generation/ki_e2po_v3_15k_1000/generated_ESR1.csv --input-scope all-attempts --output-dir runs/property-check` |
| Candidate-reference input | `evaluation/docking_candidate_selection/select_docking_candidates.py`; auto-discovery retains original experimental subdirectory names |
| Vina input | `evaluation/evaluate_e2po_1000_docking_chunked.py`; externally prepared receptors/reference ligands under its explicit `--receptor-root` are still required, not supplied by score CSVs |
| Statistics input | `tools/audit_and_plot_mean_vina_target_loto.py --per-target-csv <compatible-summary.csv> --detailed-csv <compatible-docking.csv> --output-dir runs/statistics-check`; the deposited master/statistics outputs are NOT substitutes for those input schemas |

Do not execute cache generation, preference preparation, model sampling, docking or statistical analysis over the historical output directories. Use a new output directory and the explicit model/ESM/projection arguments appropriate to the experiment. Optional beta-calibration JSON files, prepared receptors, actual protein cache tensors and recovered historical projection parameters are not present; this reorganization does not synthesize them or change fallbacks. Historical `source_csv`/provenance strings inside immutable result tables are retained as evidence and can name old locations. Use the file catalog below for the current location; they are not rewritten as newly verified provenance.

## Interpretation limits

Historical Diversity definitions differ between evaluators; do not merge columns as if formulas were identical. Some old SA code substituted a constant on error; preserve error/missingness fields rather than reinterpret them. Validity requires the real attempt denominator. Selected docking rows do not establish a generation-wide docking-success denominator. Historical statistical tables carry their original Wilcoxon/BH/bootstrap results and comparison families; no statistical inference was rerun here. Historical v3a→v3 checkpoint lineage, projection identity and final manuscript adoption remain unverified. The most recent separate N=1 invalid output is not evidence that every historical molecule was invalid. No model weights, scientific values, training hyperparameters or diffusion/optimization formulas were changed by this data organization.
